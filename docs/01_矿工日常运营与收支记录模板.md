# 矿工日常运营与收支记录模板（第 07 课配套）

> **填写原则**：技术运行指标、链上实际到账奖励与现金支出分开记录；尚未发生或无法核实的项留空，不用代币未变现的估算价格冲抵现金支出。

## 一、节点与版本基线

| 字段 | 记录值 | 说明 |
|---|---|---|
| 子网编号（`netuid`）与名称 | | 例如：本地教学链 `netuid 2` / 主网 `netuid 13` |
| 网络环境（`--network`） | | `local` / `test` / `finney` |
| 矿工 Hotkey SS58 地址与 UID | | 仅记录公钥地址，严禁填写助记词或私钥 |
| 登记端点（`ip:port`） | | 链上元图 `axon` 字段值 |
| `bittensor` SDK / CLI 版本 | | 执行 `btcli --version` 的输出 |
| 子网仓库分支与 Commit | | 执行 `git rev-parse --short HEAD` 的输出 |
