# Bittensor 14 天开发者共学营 · 学习计划与每日任务

## 学习安排说明

两周的安排：

- **第一周（Day 1–7）**：看懂生态和规则。配好钱包和命令行，读链上账本，理解验证者怎么打分，算清楚当矿工的成本。
- **第二周（Day 8–14）**：在**本地教学链**上动手，依次做矿工和验证者：注册身份，跑起矿工并接收验证者的签名请求，排查故障，再作为验证者打分、把权重提交上链，最后用 PM2 和 Docker 守护服务。

第二周用本地教学链，原因有两个：公开测试网上，学员拿不到足够质押来取得验证许可，没法真正提交权重；本地链自带测试 TAO，每一步都能拿到真实的链上结果。公开测试网只作为 Day 8 的选做体验。

### 环境要求

- **系统**：macOS 或 Linux。官方说明挖矿和验证不支持 Windows，Windows 学员请用 WSL 2 或租一台 Linux 云主机。
- **工具**：Python 3.10–3.14；第二周需要 Docker（本地教学链）。
- **命令行**：只装 `bittensor` 这个包（当前 11.x），它同时包含 SDK、`btcli` 和钱包。**不要装 `bittensor-cli`**：那是旧的独立包，装出来的 `btcli` 停在 9.x，参数写法和课程对不上。已经装过旧版的同学，按配套文档 `docs/00_环境安装与版本说明.md` 先卸载再安装。
- **配套代码包**：`bittensor-camp-kit`，各天用到的脚本见对应日期。
- **交互式实战手册**：`Bittensor_14天共学营_交互式实战手册.ipynb`。按 Day 1–14 逐天编排，把命令行查询、Python SDK 动手编程题（`TODO 0`–`TODO 4`）、矿工 Bug 修复与验证者权重上链整合在同一个 Notebook 中，支持在 VS Code / Cursor / JupyterLab 中边看边跑，也可按各天命令在终端直接运行脚本。
- **旧教程提醒**：网上很多教程基于 btcli 9.x 和 SDK 10.x，常见的 `--wallet.name`、`--subtensor.network`、`bt.Axon`、`bt.Dendrite` 在新版里都已改掉或删除。遇到对不上的命令，以 `btcli <命令> --help` 和官方[迁移指南](https://www.bittensor.com/docs/migration)为准。

## 第二周：在本地教学链上做矿工和验证者

第二周的教学子网任务是“中文材料结构化提取”：验证者发出一段中文快讯，要求矿工提取项目名称、融资金额、领投机构、子网编号四个字段，并给每个字段附上原文原句。原文里没有的字段要填空值。验证者检查原句是否真的出自原文、字段是否正确、响应快不快。

### Day 8：启动本地教学链并注册身份

**学习资源**：[Local development](https://www.bittensor.com/docs/guides/local-development)、[Mining](https://www.bittensor.com/docs/guides/mining) 的注册一节；配套脚本 `scripts/start_localnet.sh`、`scripts/setup_localnet.sh`；配套 `Bittensor_14天共学营_交互式实战手册.ipynb`（Day 8 `TODO 3`）

**验收题目**
1. 运行 `bash scripts/start_localnet.sh` 启动本地链（12 秒出块模式），再运行 `bash scripts/setup_localnet.sh`：创建教学子网，注册验证者、你的矿工和两个陪练矿工，并给验证者质押。截图脚本最后的 `btcli wallet registrations`（或 Notebook 中 `sub_local.neurons.uid`）输出，标出你的矿工 UID。
2. 执行 `btcli query metagraph --netuid 2 --network local`，截图并指出：哪个 UID 有验证许可（`validator_permit`）？为什么矿工没有？
3. 回答：注册时链上提示的价格，下一个人注册时会怎么变化？（提示：注册价格每块衰减，每成功注册一次就上涨）
4. 选做：如果助教发放了公开测试网 TAO，在测试网任选一个开放注册的子网完成一次注册，截图交易结果。

### Day 9：跑起矿工，完成首次交付

**学习资源**：第 06 课后半部分；[Signed requests](https://www.bittensor.com/docs/guides/signed-requests)；配套 `arena/day09_10_miner/camp_miner.py`、`practice_bots.py`

**验收题目**
1. 在两个终端分别启动你的矿工和两个陪练矿工（都会把各自的 `ip:port` 写上链）：
   - 终端 1：`python arena/day09_10_miner/camp_miner.py --serve`
   - 终端 2：`python arena/day09_10_miner/practice_bots.py`
   再用 `btcli query metagraph --netuid 2 --network local` 截图，确认三个矿工 UID 都已登记 `ip:port`。
2. 在终端 3 运行验证者（只评分）：`python arena/day11_validator/camp_validator.py --score-only`。截图两处：
   - 你的矿工日志：收到哪个验证者 hotkey 的签名请求、发生了什么报错
   - 验证者输出：你和两个陪练矿工各得多少分、扣分原因是什么
3. 回答：
   - 为什么链会拒绝把 `127.0.0.1` 写成端点？开着代理软件时，为什么自动探测到的 IP（如 `198.18.x.x`）可能不能用？
   - 矿工怎样判断一个请求真的来自有验证许可的验证者？（提示：`bt.http_auth.verify` 签名校验 + 查元图 `validator_permit`）

### Day 10：矿工排错与优化

**学习资源**：第 07 课完整视频；配套 `arena/day09_10_miner/diagnose_node.py`

**验收题目**
1. 保持矿工运行，执行 `python arena/day09_10_miner/diagnose_node.py --test-403`，截图：
   - 本机端口监听、链上登记端点一致性、`ulimit -n` 三项检查结果
   - 第 4 项用无验证许可的 hotkey 请求你的矿工时，矿工返回 `HTTP 403 Forbidden` 的拦截结果
2. 修复 `camp_miner.py` 里的两个缺陷（提示：看 `make_evidence` 和 `extract_field`）。Day 9 的结果里，你的矿工会被判“依据不在原文中”或直接报 `HTTP 500`。找到问题代码并修改后重启矿工，再跑一次 `python arena/day11_validator/camp_validator.py --score-only`。提交：
   - 你修改了哪几行（代码截图）
   - 修复后连续 3 轮的得分截图（你的矿工得分高于两个陪练矿工）
3. 回答：真实子网里，矿工在线却一直收不到请求，按顺序列出你会检查的 3 个地方。

### Day 11：成为验证者，提交权重

**学习资源**：第 08 课完整视频；[Validating](https://www.bittensor.com/docs/guides/validating)；配套 `arena/day11_validator/camp_validator.py`、`uid_monitor.py`；配套 `Bittensor_14天共学营_交互式实战手册.ipynb`（Day 11 `TODO 4`）

**验收题目**
1. 打开 `camp_validator.py` 读懂流程（可在 Notebook 中先完成 `TODO 4` 手写 EMA 与权重归一化练习），然后去掉 `--score-only` 运行 `python arena/day11_validator/camp_validator.py`。截图：
   - 第 1 步：验证者 UID、质押和验证许可
   - 第 3 步：每个矿工的本轮得分、移动平均分（EMA）和归一化权重
   - 第 4 步：链返回的提交结果（成功时的区块哈希）
2. 等约 2 分钟（过一个 reveal 周期）后运行 `python arena/day11_validator/camp_validator.py --show-weights`，截图链上已解密生效的权重，和第 1 题提交的比例对照。
3. 运行 `python arena/day11_validator/uid_monitor.py --rounds 3 --interval 12`，截图连续 3 次读取矿工的排名、`incentive`、上个 epoch 排放和保护期状态。
4. 回答：
   - 为什么验证者用移动平均分（EMA），而不是只看最新一轮？
   - 开启 commit-reveal 的子网上，提交权重后立刻读回，为什么还看不到新权重？
